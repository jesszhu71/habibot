# This is the code for **Habibot**, the discord bot that will help keep your shared living space clean and organized!

- The purpose of this Discord channel and Habibot is to improve communication and organization within your household.
- This includes things like: assigning and tracking chores to each member, keeping a shared grocery list, shared bills manager, and a shared calendar for events going on in the house.
- Habibot takes care of the task tracking and list building in support of these actions within the discord server.
- Setup for the discord server is simple, households will have the following chats: **social**, **events**, **shopping**, **chores**, **bills**
- There is a point system to encourage the completion of chores which can be exchanged for prizes (we said stickers, but up to your own choice)


### This bot can be run locally for a discord server with this [tutorial](https://discordpy.readthedocs.io/en/stable/discord.html) Make sure to swap in your own token and channel IDs. 


### note: this is just a prototype for a class demo, the functionality of the task tracking and list building within chats is sufficient, but the notification process for the remaining chats for the remaining functionalities are manually prompted for ease of demo presentation. The functions for these features are slightly modified and are invoked in a "command line" like channel.
